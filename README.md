# proftest

Статический тренажер профтеста для номинации лидеров в информационной работе.

## Структура

- `index.html` - разметка приложения
- `styles.css` - стили
- `script.js` - логика тестирования
- `tests.json` - банк вопросов, лица профсоюза и тренировочные медиавопросы
- `logoprofkom.jpg` - логотип

## Запуск локально

```bash
python -m http.server 8000
```

После запуска откройте `http://127.0.0.1:8000/`.

## Деплой на Vercel

Проект не требует сборки. При импорте репозитория в Vercel можно выбрать:

- Framework Preset: `Other`
- Build Command: пусто
- Output Directory: `.`
